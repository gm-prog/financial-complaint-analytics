Place the final Power BI file here locally (for example, `ComplaintAnalytics_Backup.pbix`). PBIX files can embed the underlying data; they are ignored by Git by default. Share the PBIX separately through the internship portal unless you have confirmed permission to publish the embedded source data. If publication is authorised and the file is below GitHub's regular per-file limit, the PowerShell publishing script supports an explicit `-IncludePowerBI` switch.
